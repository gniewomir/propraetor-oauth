# v1 explicit non-goals

Out of v1 scope until requirements name them: OIDC and ID tokens, RFC 7009 token revocation endpoint, RFC 7662 introspection, RFC 8414 discovery metadata, device code, implicit grant, Resource Owner Password Credentials grant, Authorization Code for Confidential Clients, Refresh Tokens for Client Credentials, remote Operator HTTP admin API, and an in-process product Resource Server (Sample Resource Server remains test-only per ADR-0005). Rate limiting and audit logging are in scope (ADR-0031, 0038, 0039).
