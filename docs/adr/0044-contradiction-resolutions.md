# Contradiction resolutions (framing)

Resolved doc contradictions without expanding the v1 grant/HTTP allowlist: Scope catalog is Operator-managed (not compile-time fixed); admin CLI goes through the domain; audit purge is per-run `--older-than` only (unified under ADR-0060); JWKS URL follows `{Issuer URL}/.well-known/jwks.json` by convention; no client-facing RFC 7009 (CLI Refresh Token invalidation is Operator-only); Access Token TTL is fail-closed capped at start (ADR-0047)—“recommended not enforced” wording is obsolete; `jti` is correlation-only; in-memory rate-limit store is non-production multi-instance. Later security grilling added further fail-closed caps (ADR-0052, 0059) without changing grants.
